Builds

Scan eaglercraft-launcher_files/versions/ and every .html file found is remembered here — it stays listed across page reloads even if the file is later moved or deleted, until you remove it yourself with the Delete button below.

  1. Find your Eaglercraft build's .html file (and its matching ..._files folder, if it has one).
  2. Drop the .html file straight into eaglercraft-launcher_files/versions/ — the companion folder can sit alongside it, it'll be ignored.
  3. Come back here and click Refresh below.
  4. Pick the versions folder itself when the folder picker opens — every .html file found there gets remembered.

On iOS: Safari can't pick a whole folder, so tap Refresh and select the build .html file(s) directly instead — they don't need to be moved into versions/ first.

Add local build file(s)

Pick one or more Eaglercraft build .html files directly — they don't need to already be inside eaglercraft-launcher_files/versions/. For a build to keep working after a page reload, though, make sure a copy of it actually ends up in that folder (move it there, then click Refresh instead, if you want it to stick around long-term).

Add a build link

Have an Eaglercraft build hosted online instead of a local file? Paste its link here and it'll show up alongside your local builds, ready to launch.

EaglerForge Injector

Adds a modding API (method hooking, reflection, custom classes) to an unminified, unobfuscated, unsigned EaglercraftX offline build. It's a separate browser tool by the EaglerForge project — it runs entirely client-side (upload a build, it patches it, you download the modded copy), so it opens in its own tab rather than inside the launcher.

  1. Click Open Injector above — it opens eaglerforge.github.io/EaglerForgeInjector in a new tab.
  2. On that page, upload your unminified/unobfuscated/unsigned EaglercraftX build .html file.
  3. Let it patch the build, then download the resulting modded .html file.
  4. Drop that file into eaglercraft-launcher_files/versions/ like any other build, then hit Refresh above so it shows up here.

Wispcraft Injector

Patches WISP tunneling into an EaglercraftX 1.8 build so it can join regular online-mode Minecraft servers, not just Eaglercraft-specific ones. Built by Mercury Workshop. Unlike the EaglerForge tool above, this one doesn't have a hosted page — you download a small standalone injector.html file and run it locally instead.

  1. Click Get Injector above — it opens the "Continuous Build" release on GitHub.
  2. Under Assets, download the injector.html file (save it anywhere, e.g. your Desktop or Downloads — it doesn't need to live in this launcher's folder).
  3. Double-click that downloaded injector.html to open it in your browser, then use its file picker to upload your EaglercraftX 1.8 build .html file.
  4. It'll process the file locally and give you a download link for the patched copy (named something like wisped-eagler.html).
  5. Move that downloaded file into eaglercraft-launcher_files/versions/, then hit Refresh above so it shows up here.
